BUGS FOUND AND FIXED DURING THIS IMPLEMENTATION (fix-retest cycle)
--------------------------------------------------------------------------
1. ProcessRunner.psm1: cross-module-instance process registry mismatch
   under Set-StrictMode ("Eigenschaft ProcessId kann nicht gefunden werden").
   Root cause: sibling modules each re-import ProcessRunner.psm1 -Force,
   creating separate $script: scopes. Fixed by moving the registry to a
   single $global: variable. Verified by re-running the fixture suite
   (0 failures after the fix, previously failing at the RAM fixture step).
2. GpuTests.psm1: same root cause via the shared $moduleDir variable name
   inside Initialize-HsD3D11ComputeVerifier. Fixed by using $PSScriptRoot
   directly. Verified by re-running the fixture suite.
3. CpuTests.psm1: Prime95 monitoring loop checked process exit before
   checking results.txt, so a fast-exiting fixture's failure evidence was
   never read. Fixed by reordering the checks. Verified: HS-012/HS-013
   fixtures now correctly report FAIL.
